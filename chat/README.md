
# JavaChatApp 💬

A simple desktop-based Java Chat Application with a Graphical User Interface (GUI), built using Java Swing.  
It allows users to register, log in, and exchange messages in a local environment.

---

## 🚀 Features

- ✅ User registration with input validation
- ✅ Secure login system
- ✅ Intuitive and responsive Java Swing GUI
- ✅ Message sending with optional urgency flags
- ✅ JSON file storage for message persistence
- ✅ Unit tests included (JUnit via NetBeans)

## ⚙️ How to Run the App

1. Clone the repository:
   ```bash

   ```

2. Open the project in **NetBeans IDE**

3. Run the `Main.java` file
